# 📁 Папка для 3D моделей

Поместите сюда ваши модели в формате `.glb`:

## Обязательные файлы:
- `zombie.glb` - модель зомби
- `soldier.glb` - модель солдата

## Опциональные файлы:
- `swat.glb` - модель SWAT/тяжёлого бойца

## Требования:
- Формат: GLB (GLTF Binary)
- Высота модели: ~1.8-2.0 метра
- Ориентация: смотрит вперёд (-Z)
- Позиция: ноги на Y=0

## Где взять модели:
- Blender (создать/экспортировать)
- Mixamo (бесплатные анимированные модели)
- Sketchfab (скачать в GLB)
- Poly Pizza (бесплатные low-poly)

Подробная инструкция: см. `MODELS_GUIDE.md` в корне проекта

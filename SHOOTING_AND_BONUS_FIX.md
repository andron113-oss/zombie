## ✅ Что было исправлено

### 1. Выстрелы теперь привязаны к моделям солдат
**Проблема:** Пули создавались из локальных координат солдат, поэтому при движении отряда пули оставались на месте.

**Решение:** Использовать `getWorldPosition()` для получения мировых координат:
```typescript
// Было (неправильно):
const bulletOrigin = soldier.position.clone().add(new THREE.Vector3(0, 1.2, 0));

// Стало (правильно):
const worldPos = new THREE.Vector3();
soldier.getWorldPosition(worldPos);
const bulletOrigin = worldPos.clone().add(new THREE.Vector3(0, 1.2, 0));
```

**Почему это важно:**
- `soldier.position` - локальная позиция относительно `squadGroup`
- `soldier.getWorldPosition()` - мировая позиция в сцене
- При движении `squadGroup` локальные позиции не меняются, но мировые меняются

### 2. Улучшено расположение солдат
**Проблема:** Солдаты были разнесены слишком далеко друг от друга.

**Решение:** Уменьшены интервалы и увеличен лимит отображения:
```typescript
// Было:
const count = Math.min(this.state.squadCount, 20); // Лимит 20
const spacing = 1.2; // Расстояние между солдатами
const rowSpacing = 1.2; // Расстояние между рядами

// Стало:
const count = Math.min(this.state.squadCount, 50); // Лимит 50
const colsPerRow = Math.min(count, 10); // Макс 10 в ряду
const spacing = 0.7; // Плотнее
const rowSpacing = 0.9; // Плотнее
```

**Результат:**
- Солдаты расположены кучнее (0.7 вместо 1.2)
- Больше солдат видно одновременно (50 вместо 20)
- До 10 солдат в ряду вместо 5

### 3. Визуальное обновление при сборе кубика +1
**Проблема:** При сборе кубика +1 количество солдат увеличивалось, но визуально не обновлялось.

**Решение:** Добавлен вызов `notifyState()` и логирование:
```typescript
case 'squad':
  if (this.state.squadCount < this.state.maxSquad) {
    this.state.squadCount++;
    console.log(`➕ Squad count increased to: ${this.state.squadCount}`);
    this.updateSquadVisuals();
    this.notifyState(); // Update UI
  }
  break;
```

**Дополнительно:**
- Добавлено логирование при сборе бонуса: `🎁 Collected bonus: ${type}`
- Добавлено логирование при обновлении отряда: `👥 Squad updated: ${count} soldiers visible`
